# NPIC Electronic & Telecommunication Engineering Information Portal

Official mobile-friendly, responsive information portal for the **Electronic & Telecommunication Engineering Department** at the **National Polytechnic Institute of Cambodia (NPIC)**.

## 🚀 Live Demo

The website is hosted on GitHub Pages:
**[https://mengseuph.github.io/npic-ete-portal/](https://mengseuph.github.io/npic-ete-portal/)**

## 📱 QR Code Access

This repository contains a permanent QR code (`qrcode.png`) pointing directly to the GitHub Pages URL. You can print, share, or post this QR code around the campus:

<p align="center">
  <img src="qrcode.png" width="250" alt="Official NPIC ETE Portal QR Code">
</p>

*Because the QR code points to the GitHub Pages URL, the department can update the website content, phone numbers, or social media links in the future without ever having to print a new QR code.*

## 🛠️ Features

* **Mobile-First Responsive Design:** Looks beautiful on mobile screens, tablets, and desktop monitors.
* **Branded Theme:** Elegant clean blue-and-white theme representing NPIC Faculty of Electronics.
* **Fast Navigation:** Large, high-visibility tap buttons for the official Faculty Facebook Page and the Student Telegram Group.
* **Lecturer Contacts:** Click-to-call links (`tel:`) and instant copy-to-clipboard phone buttons for easy access.
* **Zero Dependencies:** Pure lightweight HTML, CSS, and JS for near-instant load speeds.

## 📁 Repository Structure

```bash
├── index.html   # Main HTML markup and structure
├── style.css    # Modern HSL CSS styling, layout, waves, and animations
├── script.js    # Interactive copying/fallback code and notifications
└── qrcode.png   # 500x500 high-quality QR code image
```
